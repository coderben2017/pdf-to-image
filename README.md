# PDF 贴字工坊

一个完全在浏览器本地运行的 PDF 指定位置贴字与高清图片导出工具，适合单页表格 PDF。默认以 300 DPI 输出无损 PNG。

## 功能

- PDF.js 本地解析，文件不会上传服务器
- 300 / 600 DPI 高清渲染
- PNG 无损输出，保留表格文字与细线清晰度
- 点击或拖动预览定位文字，支持横向和纵向位置精调
- 支持多行文字，自定义透明度、角度和字号
- 默认位于左下方，文字块底部距离页面底部 10% 高度
- 单页直接下载，多页自动打包为 ZIP
- 中英文界面及移动端布局

## 本地开发

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库并推送到 `main` 分支。
2. 打开仓库的 `Settings → Pages`。
3. 将 `Build and deployment` 的来源设置为 `GitHub Actions`。
4. 推送后，项目内的工作流会自动完成构建和部署。

Vite 已使用相对资源路径，因此仓库名不影响部署地址。
